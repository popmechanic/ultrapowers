# The facts handed to the landing judge carry the exam's own assertions, clause by clause, and the facts question is asked per Machine clause

**Grammar:** claims-v1

**Claim:** `facts` carries, per exam and per `Run:` line, the assertion text the run measured — the exam file's test names and its assertion lines for the cited clauses, and the `Run:` command itself — capped (4,000 chars), so "given the facts" can raise a score as well as lower it; and the question is asked per Machine clause over that clause's own leg, which is #1167's per-leg step. (quoted from #1210)
**Summary:** This changes what the judge is shown when it decides whether a task's claim holds: today it sees only that the checks passed or failed, and from here it also sees what those checks actually asserted, clause by clause. It exists because on the last five runs the judge's confidence went down on 14 of 17 tasks once it was handed a bare pass — a pass with nothing behind it reads as doubt rather than proof (n=5 runs, 17 tasks, runs 203–207). After this run the judge is asked about each clause with that clause's own evidence in front of it, so a strong exam can raise its confidence instead of only lowering it; this is an experiment read over the next five runs, and its rollback is one switch that returns to the bare pass.

**Goal:** #1210: two pure functions in `factory/facts.mjs` that turn an exam file's text into per-clause assertion text and build a per-clause facts array; a per-clause facts question and a whole-claim assertions question in `factory/questions.json`, the old question kept verbatim as the rollback; a `landing.facts.assertions` cell in `factory/policy.json`; `readLanding` in `factory/judge.mjs` asking those questions when handed `clauseFacts`; and `measure` in `factory/engine.mjs` reading the exam files off the candidate clone and handing the array in.
**Closes:** #1210

**Tech Stack:** Node 24 ESM, no new npm dependency.
Spec: none on disk — issue #1210 is the brief (map #1131; #1167's per-leg step), and everything a worker needs is in the Context. The sandbox holds no spec.
