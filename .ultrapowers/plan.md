# The Jev factory's engine: the loop, its worker, its judge, its tools and its three roles, in five files that fit the budgets

**Grammar:** claims-v1

**Claim:** do: point the factory at the fixture plan and run it; see: every task adopted through a fold on its own landing, the exam and Jev deciding each one, the discovery referee dispatched for no routine task, and the whole of it in five files that fit the budgets I set. (elicited)
**Summary:** This is the Jev factory's engine: the loop, its worker, its judge, its tools and its three role files, built on the branch the prototype earned. It exists because the old engine is 7,300 lines of hand-written grading and the prototype showed the same fixture merging green in half the wall with Jev grading each landing. You get a run that is a search rather than a pipeline — speculative landings, a fold on every adoption, the referee off the critical path — and the old fleet untouched as the rollback until five green runs.

**Goal:** Map #1131's engine ticket: `factory/engine.mjs`, `factory/worker.mjs`, `factory/judge.mjs`, `factory/tools.mjs` and `factory/roles/{implement,exam,resolve}.md`, each within the budget the spec signed (engine ≤ 1,500 lines, worker ≤ 200, judge ≤ 200, tools ≤ 200, roles ≤ 900 words together), reading `factory/questions.json` and `factory/policy.json` as landed by #1135, driving the fixture plan `evals/fixtures/claims/plan.md` through the real kernel on every landing. Inert on main: nothing under `fleet/` imports it and no run executes it until the boot plan names an engine sha. This is an `experiment` under the floor — n = 9 prototype runs on one fixture — and its rollback is the old engine at `fleet/run-engine.mjs`, untouched by every task here.

**Tech Stack:** Node 24 ESM (`.mjs`), `@anthropic-ai/claude-agent-sdk` 0.3.274 (`fleet/package.json` carries the dependency set; `factory/` adds none — the SDK is added to `fleet/package.json` by Task 1), Python 3 for the kernel (`skills/ultrapowers/kernel/fold_wave.py`, sha-pinned manyana beneath it, unchanged), the existing `fleet/jev-client.mjs`, `fleet/kata-client.mjs` and `fleet/run-waves.mjs` consumed as-is.
Spec: `docs/superpowers/specs/2026-09-17-jev-factory.md` (laptop only; nothing below asks a worker to open it — what a worker needs is in its Context).

**Parallelization rationale:** wave 1 is four wide — worker, judge, tools, roles share no file and each carries its own contract, with the four call shapes stated as one literal block in every Context so no task waits on another's shape. Wave 2 is the engine alone, and the chain is justified by runtime behaviour, not shape: the engine's Proof drives the fixture plan through the real worker, judge and tools in the sandbox, which no fake can stand in for, so it must follow the tasks that produce them.

## Global Constraints

- No direct Anthropic API call and no `anthropic` SDK anywhere under `factory/`: every model call is one `query()` of `@anthropic-ai/claude-agent-sdk`, which rides the edge-injected bearer exactly as `claude -p` does. A file under `factory/` that imports `@anthropic-ai/sdk` or sets `x-api-key` is a blocking finding.
- Models never run git. Every `git` and every kernel invocation is the engine's own `child_process`; every worker's `disallowedTools` carries `Bash(git *)`, and the engine's confinement hook denies any `Edit`/`Write` outside the task's Files.
- A judgment is a question in `factory/questions.json` read through `factory/judge.mjs`, never a regular expression over model prose and never a threshold literal in code: every number the judge compares against is read from `factory/policy.json`.

### Task 1: The worker — one `query()` per dispatch, confinement as a function

**Type:** implementation
**Review:** peer

**Files:**
- Create: `factory/worker.mjs`
- Modify: `fleet/package.json`
- Test: `fleet/tests/test_factory_worker.mjs`

**Claim:** A dispatch is one call that runs one worker in one clone and answers with what it did, and a worker that reaches for a file it was not given is refused before it touches it. (derived)
Machine: M1. `runWorker({ cwd, prompt, systemPrompt, model, files, schema, mcpServers, maxTurns, maxBudgetUsd, onMessage }, deps)` awaits one `deps.query()` iterator to its `result` message and resolves `{ result, denials, turns, wall_ms }`, where `result` is that message, and `turns` counts its `assistant` messages. M2. The options passed to `query()` carry `settingSources: []`, `permissionMode: 'bypassPermissions'`, `cwd`, `systemPrompt`, `model`, and a `disallowedTools` list containing `Bash(git *)`, `WebFetch`, `WebSearch` and `Agent`; `outputFormat: { type: 'json_schema', schema }` is present exactly when `schema` is given, and `mcpServers` is passed through when given. M3. The options carry one `hooks.PreToolUse` callback which, for a tool named `Edit`, `Write`, `MultiEdit` or `NotebookEdit`, resolves `{ hookSpecificOutput: { hookEventName: 'PreToolUse', permissionDecision: 'deny', permissionDecisionReason } }` when the resolved `file_path` is outside `cwd` or not in `files`, resolves `{}` otherwise, and appends `{ tool, path }` to the `denials` the call answers on each deny. M4. `interruptWorker(handle)` calls the iterator's `interrupt()` once and resolves what it resolves; `runWorker` answers that handle as `handle` beside the promise when called as `startWorker(...)`. M5. `factory/worker.mjs` is 200 lines or fewer, and `fleet/package.json` lists `@anthropic-ai/claude-agent-sdk` under `dependencies`.

**Authorized-by:** #1131 (the worker layer on the Agent SDK; the audit comment of 2026-09-17); spec `docs/superpowers/specs/2026-09-17-jev-factory.md` §The worker layer

**Interfaces:**
- Consumes: none
- Produces: `runWorker(opts, deps) -> Promise<{ result, denials, turns, wall_ms }>`
- Produces: `startWorker(opts, deps) -> { promise, handle }`
- Produces: `interruptWorker(handle) -> Promise<unknown>`

**Context:** The prototype's `worker()` in `factory/proto/loop.mjs` (lines 83–115) is the shape, measured on nine runs: `settingSources: []` turns CLAUDE.md, skills and project hooks off; confinement is an in-process `PreToolUse` hook because `canUseTool` is shadowed under `bypassPermissions` — the SDK warns so at start, and the hook caught one real escape on the prototype. `files` are paths relative to `cwd`; resolve `tool_input.file_path` against `cwd` and compare the relative path, treating anything that begins `..` as outside. The four call shapes every task here shares, as one literal:

`runWorker({ cwd, prompt, systemPrompt, model, files, schema, mcpServers, maxTurns, maxBudgetUsd, onMessage }) → { result, denials, turns, wall_ms }` · `makeJudge({ ask, questionsPath, policyPath, log }) → { readTask, readLanding, gradeFinding, readNote, readAmendment, readSupervisor }` · `factoryTools({ kata, projectId, task, candidates }) → the SDK MCP server config named 'factory'` · roles at `factory/roles/{implement,exam,resolve}.md`.

`onMessage`, when given, is called with every message the iterator yields, so the engine's supervisor reads the stream without a second consumer. `deps` is the second argument and defaults to `{ query }` from the SDK, so an exam can drive a fake iterator that yields `system/init`, a few `assistant` messages, one `tool_use` whose hook the exam invokes directly off the captured options, and a `result`. The SDK's `Query` object exposes `interrupt()`; capture the object `query()` returns to serve `interruptWorker`. `fleet/package.json` gains one dependency line for `@anthropic-ai/claude-agent-sdk` at `^0.3.274` and nothing else in that file moves — the lockfile is the worker's to regenerate with `npm install` in `fleet/`.

**Proof:**
- Test: `fleet/tests/test_factory_worker.mjs`
- Legs: (a) with a fake `deps.query` that yields one `system` message, three `assistant` messages and one `result`, `runWorker` resolves `result` equal to that last message, `turns` equal to 3, and a numeric `wall_ms` [M1]; (b) the options object the fake `query` received carries `settingSources` deep-equal to `[]`, `permissionMode` equal to `'bypassPermissions'`, the given `cwd`, `systemPrompt` and `model`, and a `disallowedTools` array containing each of `Bash(git *)`, `WebFetch`, `WebSearch`, `Agent` [M2]; (c) called without `schema` the options carry no `outputFormat`; called with `schema: { type: 'object' }` they carry `outputFormat` deep-equal to `{ type: 'json_schema', schema: { type: 'object' } }`; called with `mcpServers: { factory: 'x' }` they carry that same object [M2]; (d) for each of `Edit`, `Write`, `MultiEdit`, `NotebookEdit`: invoking the captured `hooks.PreToolUse[0].hooks[0]` with that `tool_name` and `tool_input: { file_path: '<cwd>/outside.txt' }` when `files` is `['inside.txt']` resolves a `hookSpecificOutput.permissionDecision` of `'deny'`, and the call's `denials` afterwards contains `{ tool: <that name>, path: 'outside.txt' }`; for `Edit`, with `file_path` `'<cwd>/inside.txt'` it resolves `{}`, and with `file_path` `'<cwd>/../escape.txt'` it resolves `'deny'`; with `tool_name: 'Read'` and the outside path it resolves `{}` and `denials` is unchanged [M3]; (e) `startWorker` with a fake `query` whose returned object carries an `interrupt()` that resolves `'ok'` answers a `handle`, and `interruptWorker(handle)` resolves `'ok'` after calling it exactly once [M4]; (f) the line count of `factory/worker.mjs` is at most 200, and `fleet/package.json` parsed as JSON has `dependencies['@anthropic-ai/claude-agent-sdk']` as a non-empty string [M5].
