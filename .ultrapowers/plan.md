# Autoresearch over the tagged runs: one laptop command reads which questions predict a task's fix rounds and parks

**Grammar:** claims-v1

**Claim:** After this run I can run one laptop command over the tagged runs and read, per candidate question, whether Jev's answers to it predict a task's fix rounds and parks better than the authored difficulty read, with held-out numbers. (elicited)
**Summary:** Today the questions Jev is asked about a task were written by hand, and the record of 33 factory runs says nothing about whether they predict anything. This script asks candidate questions over every task on the record, fits a small model against how those tasks actually ended, and reports which questions carry signal. You get a learned reading of what to ask instead of an authored guess, and nothing on the fleet changes until that reading clears the floor.

**Goal:** #1132 (map #1131): a laptop script, `skills/ultrapowers/scripts/autoresearch.py`, run by hand over the evidence tags, that reads every task's outcome labels off its run's `events.jsonl`, proposes candidate questions with `claude -p`, answers them over every task through the Jev client, fits a plain logistic regression on a fixed split, and reports held-out AUROC per outcome for the authored `difficulty` read alone, for each candidate added, and for an ablation dropping each in turn — one table on stdout and one JSON. Nothing enters `factory/questions.json` from this plan.
**Closes:** #1132

**Tech Stack:** Python 3 standard library only for the script and its exam — no numpy, no CatBoost, no new dependency; Node 24 ESM only as the Jev fan-out's child process (`fleet/jev-client.mjs`); pytest for the exam (the sandbox installs `python3-pytest python3-pytest-xdist`, `fleet/setup-script.mjs` line 159).
**Exam command:** python3 -m pytest -q {paths}
**Spec:** none on disk — #1132 and its one comment of 2026-09-21 are the brief, and everything the worker needs is in its own Context. The sandbox holds no spec.

Logistic regression with an intercept: weights and intercept start at 0; full-batch gradient descent, 2000 steps, learning rate 0.1; the gradient is the mean over training rows of (σ(w·x + b) − y)·x for the weights and of (σ(w·x + b) − y) for the intercept, plus an L2 term 0.01·w on the weights only; σ computed stably (`exp(-z)` branch for z ≥ 0, `exp(z)` for z < 0). A held-out task's score is w·x + b.
