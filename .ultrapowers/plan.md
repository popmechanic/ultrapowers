# A finished result waits for its siblings — the age clause fires only when nothing is left in flight, so a run-67 replay is expected to fold three times, not five

**Grammar:** claims-v1

**Claim:** When I read a run's record, a finished result waits for its siblings instead of buying its own fold: a fold happens only when it lets a queued task start, ends the run, or nothing else in the run is still being built or reviewed. (elicited)
**Summary:** This is the second turn of the fold rule, taken on run-143's reading: both of that run's age-out folds carried a single task that the very next fold would have carried for free. It exists so that a finished result never pays a whole suite for its own adoption while a sibling is still being built or reviewed — the age clause now waits until nothing left in the run could release a task or end it. After this run a plan like run-67's is expected to fold three times instead of five, the record still says why every fold happened, and the sims that need a fold at every landing still get one with the same argument they pass today.

**Goal:** #1006's decision comment of 2026-09-15 (operator): experiment (b) from the run-143 reading — `aged` fires only when no sibling task is implementing or in review, so a finished, unadopted result ages out only when nothing left in the run could produce a `released` or `end` fold. Run-143 (tag `ultra/evidence/run-143`, run-67's plan replayed on engine `e0526443`) made five folds — `released` +9.5m [2,3,6,7,8,9], `aged` +14.3m [10], `released` +19.3m [1], `aged` +26.2m [5], `end` +34.9m [4] — where task 10's result (landed +4.5m, during fold 1) would have ridden fold 2 with task 1, and task 5's (landed +16.6m) would have ridden the `end` fold with task 4; expected on the next replay: three. Everything else the redrive (run-140, `3f2b18ae`) defined stays: `released` and `end` as they are and asked first, `why` on every epoch event, `args.foldAgeMs` with its default of the larger of 60 s and the baseline wall, and `foldAgeMs: 0` as the BASE-of-run-140 rule — a fold at every landing, siblings in flight or not — which is what the sims that are not about the fold trigger pass.
