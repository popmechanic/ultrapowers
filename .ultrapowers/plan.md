**Claim:** When a run that changed the engine merges, its record says which of the changed lines a sim actually ran and which none did — a reading beside the receipt, never a gate. (derived)
Machine: M1. `fleet/engine-coverage.mjs` exports `engineCoverage({ tree, base, head, file, sims, width })` which resolves to `null` when `git diff -U0 <base> <head> -- <file>` in `tree` adds or modifies no line, and otherwise to `{ file, base, head, changed, reached, unreached, sims }`: `changed` the ascending new-side line numbers of every added or modified line of that diff; `sims` one `{ sim, exit, ms, reached }` per entry of the `sims` argument in the order given, each run as `node <tree>/<sim>` with cwd `tree` and the inherited environment plus `NODE_V8_COVERAGE` set to a fresh directory of its own under the OS temp dir, at most `width` at once; `reached` the ascending subset of `changed` whose count is greater than zero in at least one sim; `unreached` the rest of `changed`, ascending. M2. A line's count in one sim is the count of the innermost range containing the line's first character — ranges of one function are listed outermost first, and offsets index the file's text as a JavaScript string, not its bytes — read only from coverage script entries whose `url` is exactly the `file://` URL of `<tree>/<file>`; an entry for a copy of the same file at another path contributes nothing. A sim that exits non-zero has its exit recorded and its coverage read all the same. M3. In `runEngine`, after the last fold and before the report object is assembled, when the integration clone's `git diff --name-only <baseSha> HEAD -- fleet/run-engine.mjs` names the file and the integration tree holds at least one `fleet/tests/test_run_engine_*.mjs`, the engine calls `engineCoverage` with those sims sorted by path and `width` the run's width, and the returned report carries the reading as `engineCoverage`; on any other run the report carries `engineCoverage: null`. The reading changes no other report field: a run whose changed engine lines no sim reaches still ends with the `tests.passed` and `coverage.complete` it would have had without the reading. M4. `fleet/CONTRACT.md`'s evidence sub-bullet (the `ultra/evidence-run-<N>` item of "The three branches on the target") names `report.json`'s `engineCoverage` as a reading that gates nothing, and `skills/ultrapowers/references/report-format.md`'s field table carries an `engineCoverage` row, between the `coverage` and `missingDeliverables` rows, stating the M1 shape and that it is never gated.
