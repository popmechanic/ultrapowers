**Grammar:** claims-v1

**Claim:** After this run, in a session where I have used ultrawrite or ultrapowers, the agent no longer ends a turn while background work is still running without first asking itself whether there is something productive to do meanwhile; it fires once per turn, only with work in flight, and a session that never used either skill sees nothing. (elicited)
**Summary:** This adds one Stop hook, declared by the two skills, that catches the moment the agent would go idle while a run, an author or a monitor is still working and puts the question you have typed a dozen times to the agent instead. It exists because a fleet session spends most of its clock waiting, and each time you asked there was productive work to do. After it the agent asks itself once per turn, lists what is in flight, and either does the next independent thing or says in one line that there is nothing.
